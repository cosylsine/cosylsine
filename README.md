## About me

I'm **Jiaxin Xu (许佳鑫)**, a master's student in Computer Technology at **Harbin Institute of Technology, Shenzhen**, advised by [Prof. Meishan Zhang](https://zhangmeishan.github.io/).

My research focuses on **information retrieval for LLM agents**: efficient reranking, agent-oriented evaluation, and long-horizon memory retrieval.

## Selected code

- **[DCI-Bench](https://github.com/cosylsine/dci-bench)**<br>
  Evaluating LLMs through direct corpus interaction, with sandboxed tools and auditable retrieval metrics.

- **[Long-document reranking](https://github.com/cosylsine/MyFlagEmbedding_for_kalm_reranker_long-doc)**<br>
  A FlagEmbedding adaptation for long-document reranker training and MLDR evaluation.

- **[Pi for DCI-Bench](https://github.com/cosylsine/pi-dci/tree/dci)**<br>
  A Pi fork adapted for DCI-Bench, with sandboxed corpus access and evaluation controls.
